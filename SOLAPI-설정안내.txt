실제 문자를 받으려면 SOLAPI 계정 설정이 필요합니다.

1. SOLAPI 가입
2. 발신번호 사전등록
3. API Key와 API Secret 발급

API Key와 API Secret의 실제 값은 서버 환경변수에만 저장하세요.

SQ7F0KXCRFCFZDXIJ58JCK9FV82HRF7A

4. 문자 발송 잔액 충전
5. Eclipse Run Configurations의 Environment에 아래 값 입력

SOLAPI_API_KEY=발급받은 API Key
SOLAPI_API_SECRET=발급받은 API Secret
SOLAPI_SENDER=등록한 발신번호(하이픈 제외)
DB_PASSWORD=MySQL 비밀번호

API Key와 Secret Key는 Git에 커밋하거나 화면 JavaScript에 넣으면 안 됩니다.
키는 반드시 Spring Boot 서버 환경변수로만 전달합니다.

MySQL Workbench에서 database/schema.sql을 먼저 실행해야 합니다.
